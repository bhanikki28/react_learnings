React State - > Local State of a component

React has two variants of data

    1. Through Props to hold the data external to the component and is not mutated by the component
    2. State is to hold the data internal to the component and is able to mutate by the component
    3. Flow of data is unidirectional from Parent to Child using props 
    4. With Props, we can pass one or more parameter
    5. Think of props flow between Parent to Child component, as Money (Salary) is been transfered from Employer to the Employee
